# Luvira Finance

Luvira AI秘書に接続する、経営者向けのリアルタイム財務管理モジュール。

## 目的

freeeの正式な記帳を待たずに、銀行・法人カード・個人立替を含む会社のお金の状況を把握する。

## MVP

- 支出・収入の手入力
- 個人カード／個人口座／現金による立替の管理
- freee APIからの銀行・法人カード明細取得
- CSV取込（APIで取得できない場合の予備）
- 固定費と今後の予定支払いの管理
- 予算対実績
- 現在残高と3〜6か月の資金繰り予測
- freee記帳済みフラグと照合
- Luvira AI秘書からの財務サマリー取得

## 設計方針

- 税務会計ソフトではなく、経営判断用の速報管理ツールとする。
- 金額計算・残高計算はアプリの確定ロジックで行い、AIは要約・説明・異常検知を担当する。
- 会社資金の支出と、個人による立替債務を分けて管理する。
- すべての変更履歴を残し、CSVエクスポートとバックアップを可能にする。

freeeを会計データの中心に置き、Luvira Financeは経営判断用の速報・予測レイヤーとして動作する。
